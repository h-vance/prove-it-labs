Read the full response including headers:

```bash
curl -i http://127.0.0.1:8101/v1/customers/cus_8823
```

Two headers carry the answer:

```
Sunset: Sat, 01 Aug 2026 00:00:00 GMT
Link: </v2>; rel="successor-version"
```

`Sunset` (RFC 8594) states when the resource stopped being served. `Link` with
`rel="successor-version"` names what replaced it. The `detail` in the body says
the same thing in prose.

Update the path in `labs/api/_stack/request.sh` to the current version, confirm
you get the account record, then run `tse check`.

1 August, and they only reported it this morning. Ask what else calls the old
version.
