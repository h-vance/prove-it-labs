The customer's theory is corrupt records in the middle of their data. Test that
theory directly, because it is falsifiable and the test is free.

If the failures were caused by specific records, they would follow those
records. Run the sync twice and compare. Do the same pages fail both times? Do
the failures move if you change the order or the page size?

If the failing position stays the same while the data behind it changes, the
data is not what is failing.

Look at **where** the run turns, not just that it turned.
