Deciding where to start is a real cost, and for some people it is the whole
barrier. This is here so you can hand that decision over and get moving.

## If you would rather just pick

Both entry points are genuinely fine. The difference is small:

- **Docker** builds the habit everything else depends on, which is proving
  whether something is running before you explain why it is not.
- **APIs** need no container knowledge and give the fastest feedback loop, so
  they are a gentler place to build the same evidence habit.

You can switch tracks at any point, and nothing is locked.
